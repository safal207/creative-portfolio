# Alexey Safonov — architectural visualization

Public portfolio for architectural visualization and interactive property presentations.

Website: https://safal207.github.io/creative-portfolio/

The site is static. `dist/` contains the published pages and media. The GitHub Pages workflow checks local references before deployment.

## Design resources

The typography uses self-hosted Instrument Serif and Manrope from the Google Fonts library. Both are licensed under SIL Open Font License 1.1; the corresponding license texts are included in `dist/assets/fonts/`.

## Evidence boundaries

- Dubai Residence is a self-initiated, AI-assisted concept, not a client commission, measured architectural drawing, BIM model, or evidence of property sales.
- The hero image adds an AI-assisted evening sky treatment to a Blender villa render. The unaltered exterior render remains available separately; the hero is an illustrative mood study, not a frame from the 3D tour.
- The 58-second villa tour is a screen recording of the local Three.js viewer. A downloaded project brief is not an enquiry submitted to anyone.
- The kitchen/dining AI visual is an editorial proposal shown beside its unaltered Blender source; generated details are not in the interactive tour.

Images, design exports, and media are portfolio evidence. No reuse license is granted by this repository.
